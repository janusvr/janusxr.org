The JanusXR project is in desperate need of a new website. The current website is still the same page from when the company shut down in 2019. The whole page, including the documentation, is entirely centered around the native client, and doesn't even link to the web client, the github repos, or anything that might indicate signs of life in the project.

Our goal for this project is to make a new website which full embraces the fact that JanusXR is now an open project, and the web client is the primary means of accessing it. We want to emphasize the mix of client and server components we offer, and focus on the functionality that the web client offers to allow users to create not just simple multiplayer 3d worlds, but a multitude of rich client applications which make use of 3d in the browser. Data visualizations, simulations, games, industrial control systems, fancy websites - and yes, "stand around in a website" is a core primitive of the engine, but the web client need not be pigeonholed like that, what we have is something that straddles the line between a web framework like React or Angular, and a game engine like Unity.

One feature that JanusXR has which is not well demonstrated is the fact that it can be integrated into and display in or underneath a traditional 2d website. Interacting with the 2d world can cause changes in the 3d world, and vice versa. So our homepage should load up and feel like just a regular 2d website with a fancy hero image. The hero image is in fact a janus room, and scrolling or otherwise interacting with the site gradually reveals that you are, in fact, inside of a 3d world - the 2d images and text are actually mapped onto 3d objects in the world, and as we move to different sections, it's like the 3d space is an interactive museum space, with different topics set up arranged in physical proximity with each other.

The style of the page should maintain the same "80s cyberpunk" green/white/dark grey color theme, evocative of an old monochrome green monitor. We want to emphasize the fact that JanusXR is an open project for hosting decentralized virtual world content, and call out some of the possible uses we see for the engine. We'll want the following sections:

- JanusXR branding
- What is JanusXR?
- How can I get JanusXR?
- How can I build for JanusXR?
  - Room markup
  - Scripting
  - Infrastructure
  - Drastically expanded documentation
- JanusXR Timeline
